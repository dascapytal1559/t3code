# File Explorer

The File Explorer loads a folder when you expand it, so large projects are not capped by a
whole-workspace file limit. Files and folders ignored by Git remain visible and fully interactive,
but use a muted color similar to VS Code. You can still open, preview, drag, and mention them in a
chat.

Path and content search continue to omit Git-ignored files. Expand an ignored folder to browse its
contents directly.

T3 Code always hides `.git`, `.DS_Store`, and `.convex` entries from the Explorer.
